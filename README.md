# Trabalho 07 - Modelagem e Avaliação de Desempenho com SPN


## Estrutura do Projeto
* `model/`: Modelo formal no Jupiter Analytics (`.json`).
* `results/`: Resultados numéricos das simulações (CSVs e relatórios).
* `scripts/`: Script em Python para processamento de dados e geração de gráficos.
* `figures/`: Gráficos vetoriais e tabelas consolidadas geradas pelo script.
* `grafico/`: Gráficos gerados diretamente na interface do Jupiter Analytics.

## Execução dos Scripts
```bash
python3 scripts/generate_plots.py
```
